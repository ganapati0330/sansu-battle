# さんすうバトル！ 音声収録台本

全 **107本**。この順番どおりに、ひとつの音声ファイルに続けて録音してください。

## 収録のしかた

1. **1本ずつ、あいだに1秒くらいの無音**を空けて、上から順に読んでいってください
2. 無音を手がかりに、こちらで自動で切り分けます。1秒あれば十分ですが、長いぶんには問題ありません
3. 言いなおしたときは、**その場でもう一度読みなおして**ください。最後に読んだものを採用します
   （切り分け後にこちらで1本ずつ確認します）
4. キャラクターごとに別ファイルでも、3人まとめて1ファイルでもかまいません

## ファイルの仕様

| 項目 | 指定 |
| --- | --- |
| 形式 | WAV / MP3 / M4A どれでも |
| チャンネル | モノラル（ステレオでも可） |
| サンプリング | 44.1kHz 以上 |
| BGM・効果音 | **入れないでください**（あとでゲーム側と混ざるため） |
| ノイズ処理 | かけなくて大丈夫です。こちらで音量をそろえます |

読み終わったファイルをそのまま送っていただければ、
分割 → 音量の均一化 → 圧縮 → HTMLへの埋め込み まで、こちらで行います。

## 目安

- 収録時間は 3人ぶんで **10〜15分** 程度（読み上げ + 無音のみ）
- 埋めこんだあとの増加は **約1.2MB**（MP3 48kbps モノラルに圧縮したうえで埋めこみます）
- 音声が入っていない場面は、これまでどおり読み上げに切りかわります。
  **3人ぶん揃っていなくても、1人ぶんだけでも動きます**

## AI音声でも かまいません

VOICEVOX や にじボイス などの読み上げソフトで作った音声でも大丈夫です。
その場合は 1本ずつ別ファイルで書き出したものを、
`kuro_start_1.wav` のように **ID をファイル名**にして送っていただくのがいちばん確実です
（無音での切り分けが不要になります）。

## 番号の見かた

`kuro_hit1_2` = クロネコさん / ダメージ小 / 2本目
